# ДопПро

Локальная программа для педагога дополнительного образования. По пяти шагам собирает дополнительную общеобразовательную общеразвивающую программу и сохраняет её в файл Word (`.docx`).

Программа рассчитана на разные организации и все шесть направленностей. Без интернета документ собирается из готовых формулировок направленности. Ключ нейросети необязателен.

Страница проекта: [github.com/wenjiro/doppro](https://github.com/wenjiro/doppro)

## Педагогу

1. Скачайте `DopPro.exe` со [страницы выпусков](https://github.com/wenjiro/doppro/releases). На странице файл подписан «ДопПро.exe»: GitHub не оставляет русские буквы в имени скачиваемого файла.
2. Запустите файл двойным щелчком. Python устанавливать не нужно.
3. Пройдите пять шагов и нажмите «Собрать программу».

Windows может один раз показать окно SmartScreen, потому что файл не подписан. Нажмите «Подробнее», затем «Выполнить в любом случае».

При запуске ДопПро сама сравнивает свою версию с последним выпуском на GitHub. Если вышла новая, программа предложит открыть страницу загрузки. Та же проверка есть в «Настройках». В запрос уходит только номер версии, без текста программы.

Черновик и список «Мои программы» хранятся на этом компьютере в `%APPDATA%\DopPro`. Ключ нейросети лежит отдельно и в файлы программ не записывается. Экспорт из «Моих программ» можно перенести на другой компьютер.

Перед утверждением в организации текст нужно вычитать: сверить часы, даты, локальные акты и актуальные редакции нормативных документов.

### Пять шагов

1. Паспорт: название, направленность, уровень, организация, педагог, регион, город, год. Серый текст в пустом поле — подсказка, в документ он не попадает.
2. Обучающиеся: возраст, срок, часы, группа, форма обучения, календарь.
3. Учебный план: разделы, теория и практика, темы лекций и практик. Сумма часов должна совпасть с объёмом. «Составить план по названию» доступно, если в настройках указан ключ.
4. Условия: оборудование, программы, расходные материалы, профессии проб. Их тоже можно составить по названию.
5. Сборка файла Word. «Сформулировать под эту программу» просит цель, адресат, задачи и литературу по ГОСТ Р 7.0.100-2018.

Фамилия педагога и название организации в нейросеть не отправляются. Часы, даты и нормативные пункты подставляет сама программа.

Ключ задаётся в «Настройках»: Gemini, GigaChat или DeepSeek. Сертификаты Минцифры для GigaChat уже внутри программы.

## Разработчику

Нужны Windows и Python 3.10 или новее.

```bat
python -m pip install -r requirements.txt
python tools\prepare_assets.py
python main.py
```

Проверка сборки документа без окна:

```bat
python tools\selfcheck.py
```

Сборка одного exe:

```bat
build_exe.bat
```

Результат: `dist\ДопПро.exe`. Шаблоны, логотип и сертификаты уже внутри файла.

Вручную:

```bat
python -m pip install -r requirements.txt
python tools\prepare_assets.py
python -m PyInstaller --noconfirm --clean build.spec
```

### Состав

```text
main.py
gui/          окно, шаги, настройки, список программ, подсказки
core/         модель, тексты, документ, план, нейросеть, обновления
templates/    каркас docx и формулировки направленностей
data/         типовые разделы
certs/        сертификаты НУЦ Минцифры
assets/       логотип и иконка
```

`ProgramData` в `core/data_model.py` хранит ответы мастера. `core/templates_engine.py` собирает абзацы. `core/document_builder.py` подставляет их в каркас `templates/program_template.docx` через docxtpl. Каркас создаёт `core/template_factory.py`.

Номер версии — `VERSION` в `core/paths.py`. Проверка обновлений читает последний выпуск `wenjiro/doppro` и ничего не скачивает сама.
